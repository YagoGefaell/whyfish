# Opening book data

`a.tsv` … `e.tsv` come from [lichess-org/chess-openings](https://github.com/lichess-org/chess-openings)
(downloaded 2026-11-25), released under **CC0-1.0** (public domain). Columns: `eco`, `name`, `pgn`.
Used by `app/analysis/book.py` to classify book moves (📖) and name openings.

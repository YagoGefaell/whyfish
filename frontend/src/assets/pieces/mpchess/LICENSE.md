# Chess pieces: "mpchess" set

SVG chess pieces by **Maxime Chupin**, from his MetaPost package mpchess
(<https://github.com/chupinmaxime/mpchess>). The author contributed this SVG set to Lichess
himself (lila PR "Add mpchess piece set" and "COPYING file for mpchess", #12705, April 2023)
under the **GNU GPL v3 or later** (full text in `COPYING-GPL-3.0.txt`). The MetaPost package
itself is under the LPPL 1.3c.

Files taken from `lila/public/piece/mpchess` (downloaded 2026-11-27). No changes in whyfish.

Note: GPLv3+ is a copyleft licence. For a private, local app this has no practical effect; if
whyfish were ever distributed, these files (they are their own source) must be distributed under
the GPL with this notice.
